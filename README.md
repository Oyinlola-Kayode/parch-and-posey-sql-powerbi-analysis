# 📊 Parch and Posey SQL + Power BI Sales Analysis

This project delivers a comprehensive data analysis of Parch and Posey sales and customer engagement using SQL for data extraction and Power BI for visualization. The goal is to uncover actionable insights into revenue trends, channel performance, and sales representative effectiveness to drive better business decisions.

---

## 🎯 Objectives

- Analyze overall sales performance and trends over time.
- Evaluate top-performing sales reps and high-value accounts.
- Identify the most effective sales channels.
- Understand customer behavior and interaction patterns.
- Recommend strategic improvements based on data insights.

---

## 🧰 Tools Used

- PostgreSQL (SQL): for querying the relational database.
- Power BI: for dashboard creation and visual analysis.
- Microsoft Word: for documentation and reporting.

---

## 📁 Dataset Overview

The dataset contains 5 interconnected tables:

- `web_events`: Logs of customer interactions including timestamps and marketing channels.
- `accounts`: Account information linked to orders and reps.
- `sales_reps`: Performance details of sales representatives.
- `orders`: Transactional data showing revenue by order.
- `region`: Geographic classification of accounts.

---

## 🧮 Methodology

### 🔹 Data Preparation (SQL):
- Joined all relevant tables using foreign keys.
- Created custom date columns (Day Name, Day Number) for trend analysis.
- Calculated total revenue, orders, and engaged accounts.

### 🔹 Power BI Visuals:
- Built visuals to show trends by time, region, sales rep, and channel.
- Created custom dashboards showing:
  - Top accounts and reps
  - Total revenue by channel
  - Average order value
  - Web interaction patterns

## 🧠 Strategic Recommendations

- Sales Rep Training: Leverage techniques used by top reps across the team.
- Client Diversification: Reduce over-dependence on high-value accounts.
- Channel Investment: Boost underperforming channels like Twitter.
- Retention Strategy: Re-engage inactive accounts based on web interaction decline.
