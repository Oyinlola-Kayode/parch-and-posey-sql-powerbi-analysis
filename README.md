# 📊 Parch and Posey SQL + Power BI Analysis

This project analyzes sales and customer engagement data from Parch and Posey using **SQL** and **Power BI**. Insights were generated from a PostgreSQL database and visualized in Power BI dashboards.

---

## 🧰 Tools Used

- PostgreSQL (SQL Queries)
- Power BI (Visualizations)
- Microsoft Word (Documentation)

---

## 📁 Files Included

- `Parch_and_Posey Query` – SQL queries used to extract insights
- `Parch_and_Posey VISUALS.pdf` – Dashboard created in Power BI
- `Parch_and_Posey Analysis Report.docx` – Written report with insights and recommendations

---

## 📈 Key Insights

- Earlie Schleusner was the top sales rep, generating over $1M in revenue.
- EOG Resources and Mosaic were the leading accounts.
- Direct and Adwords channels drove the most revenue.
- Web interaction peaked in 2015 and declined afterwards.
